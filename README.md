# Excel_Dashboard_Project
Interactive Excel dashboard built using Pivot Tables, Power Query, and advanced formulas for data analysis and visualization.
## Overview
This project showcases an interactive Excel dashboard designed to analyze and visualize data for decision-making.

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Power Query
- Advanced Excel formulas 
- Data cleaning and preparation

## Key Insights
- Identified trends and patterns through dynamic filtering
- Built KPI-focused visualizations
- Enabled user-friendly interaction using slicers
